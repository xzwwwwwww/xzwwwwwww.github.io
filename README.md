# 我的小站

一个零依赖的静态个人网页：无需安装任何东西，双击 `index.html` 就能在浏览器打开。

## 目录结构

```
my-site/
├── index.html      # 页面结构（首页 / 生活碎碎念 / 留言信箱 / 小游戏 / 小朋友 / 你和我）
├── css/style.css   # 全部样式
├── SETUP-INBOX.md  # 留言信箱后端（Supabase）配置指南
└── js/
    ├── config.js   # ★ Supabase 密钥（按 SETUP-INBOX.md 填写）
    ├── data.js     # ★ 你的笔记和生活记录都写在这里
    ├── inbox.js    # 留言信箱逻辑（一般不用动）
    ├── game.js     # 黄金矿工小游戏（一般不用动）
    ├── pvz.js      # 植物大战僵尸小游戏（一般不用动）
    ├── minesweeper.js # 扫雷小游戏（一般不用动）
    ├── snake.js    # 贪吃蛇小游戏（一般不用动）
    ├── space-data.js # ★「你和我」的账号密码和内容都写在这里
    ├── space.js    # 「你和我」登录逻辑（一般不用动）
    ├── poem-data.js # ★ 古诗词小游戏的 100 首诗词数据
    ├── poem.js     # 古诗词小游戏逻辑（一般不用动）
    ├── sudoku-data.js # ★ 数独小游戏的 50 道题库（离线生成，均唯一解）
    ├── sudoku.js   # 数独小游戏逻辑（一般不用动）
    ├── gomoku.js   # 五子棋小游戏（本地双人 / 人机 / 在线联机，一般不用动）
    ├── kids.js     # 「小朋友」专区：涂鸦画板 / 打地鼠 / 口算小问答（一般不用动）
    ├── kids-content.js # ★「小朋友」各分类栏目与示例文章都写在这里
    ├── life.js     # 生活碎碎念在线发布（登录、图片压缩、拉取合并，一般不用动）
    ├── nav-fx.js   # 导航动效（滑动下划线 / 滚动质感，纯装饰，删了不影响功能）
    └── main.js     # 页面逻辑（一般不用动）
```

## 如何添加生活碎碎念

「生活碎碎念」页顶部有一幅温馨的小场景插画（热茶、绿植、打盹的猫，`assets/life-scene.svg`）和一条「节气 · 小站第 N 天」暖心条（节气按常见日期近似，小站生日 2026-07-19）。

「我的碎碎念」为月历视图（手帐贴纸风：奶油底卡片 + 和纸胶带 + 月份季节 emoji + 今天的日期带虚线圈）：每个有内容的月份一张月历卡片；日期是一个个小方格——有碎碎念的格子直接显示文字概述或小照片，右上角显示当天的心情小表情（发布时从 8 个 emoji 里自选），悬停（或触屏点按）放大并弹出当天的完整内容（含图片缩略图，点击可放大）；非日期条目收在月历下方「随手记」小便签里。

页面中部是「我的生活思考」组件：站长登录（留言信箱站长账号）后可随时发布人生感悟（英文版选填）；访客无需审核即可在每条感悟下评论（自定义昵称，立即公开，评论按时间逐条叠加）。需先在 Supabase 跑 `SETUP-INBOX.md` 末尾附录的 `life_thoughts` / `life_thought_comments` 建表 SQL。

两种方式添加内容，内容会合并显示（按日期归位）：

- **在线发布（推荐）**：先在 Supabase 跑 `SETUP-INBOX.md` 末尾附录的 `life_moments` 建表 SQL，然后打开「生活碎碎念」页右上角「✎ 写碎碎念」，用留言信箱的站长账号（Supabase Auth 邮箱 + 密码）登录，即可随时发布文字 + 图片（图片自动压缩，一次最多 6 张，点击可放大）。英文版正文可选填。
- **改代码**：在 `data.js` 的 `MOMENTS` 数组里加一项，重新部署：

```js
{ date: "2026-07-18", text: "今天做了什么。", text_en: "What I did today." }
```

`text_en` 是英文版文案（可选），英文模式下显示；不写就中英都显示 `text`。

（以前写的读书笔记还留在 `NOTES` 数组里存档，目前网页上不展示。）

## 首页「今天」

首页标题下方有一个「今天」卡片组件：大字号实时时钟（每秒跳动）、公历日期 + 星期、农历日期（浏览器内置中国历法换算）、趣味黄历宜忌（每天固定两条宜一条忌，清单在 `js/daily-data.js`，属趣味内容非正统黄历）。下面的标语位是「每日一句」：365 条中英双语暖心短句（也在 `js/daily-data.js`，带规范标点、约 3/4 配 emoji），按一年中的第几天轮换，想改句子直接编辑该文件。

## 留言信箱

访客可在「留言信箱」页自定义昵称留言，留言先进入待审核状态，不会直接公开。页面底部「站长登录」登录后可审核：通过、回复、隐藏、删除。留言数据存放在 Supabase，首次使用请按 `SETUP-INBOX.md` 配置（约 10 分钟），否则信箱显示“暂未开放”。

## 小游戏

「小游戏」页以方框网格入口展示七款游戏（一行两个大方框，配手绘 SVG 游戏插图、带小动画；点击方框进入游戏，悬停方框会放大，游戏画面左上角可返回列表）：

- **数独**：50 关标准数独，按给字数从易到难分四档（入门/简单/中等/困难，以难度星级标注），每题均保证唯一解；点格子后点数字键盘填入，支持笔记候选数、每关 3 次提示、重置本关，填错标红并计错误数；通关解锁下一关并记录用时与每关最佳成绩，进度自动保存
- **黄金矿工**：点开始 → 点击画布/按空格放钩 → 抓金块、钻石得分，小心炸弹；抓完全部黄金和钻石即提前通关，否则 60 秒结算
- **植物大战僵尸**：白天 10 关 + 夜晚 10 关——白天撑杆/报纸/铁桶僵尸陆续登场，寒冰射手、樱桃炸弹、食人花、窝瓜随关卡解锁；夜晚无天光（阳光全靠阳光菇），阳光菇/小喷菇/胆小菇/大喷菇（烟雾群伤、穿透防具）逐个解锁，铁栅门、橄榄球、舞王（召唤伴舞）僵尸加入；画面上方有关卡列表，通关的关卡可随时点回去重玩，进度自动保存
- **扫雷**：经典扫雷，简单/中等/困难/专家四个难度，左键翻格、右键或长按插旗，双击已翻开的数字格（周围旗子数够时）自动翻开周围格子，首次点击必安全，失败后可点「重新开始」
- **贪吃蛇**：自嘲熊版贪吃蛇——熊头蛇身吃拉面，方向键 / WASD / 触屏滑动控制，P 键暂停；标准模式撞墙失败，穿墙模式可从边界另一侧穿出，两种模式咬到自己都失败
- **古诗词**：100 关古诗词填空——从小学课标篇目到高中课标篇目难度递增，给上句填下句或给下句填上句（不写标点），答对展示全诗并解锁下一关；已通关关卡可从下拉框随时重玩，进度自动保存
- **五子棋**：15×15 标准棋盘，黑先白后，横竖斜任意方向连五即胜；支持三种模式——本地双人同机轮流下、人机对战（你执黑，电脑执白，棋型评分启发式 AI，中等强度）、在线联机（创建房间拿到 6 位房间码发给对方，对方输入房间码加入为白方，双方每 2 秒轮询同步棋局；联机对局结束后可选「再来一局」（一方先按则对方看到“对方等待中”，对方也按即开新局）或「结束对局」（对方看到“对方已离开”），信号复用房间行 status 字段，无需额外建表）；本地/人机模式支持悔棋；联机需先按 `SETUP-INBOX.md` 末尾附录的 SQL 建好 `gomoku_rooms` 表，否则显示“暂未开放”
- **消消乐**：自嘲熊三消——点选两个相邻熊头交换，凑成横/竖 3 连即消除，下落补位可连锁（连锁加分）；50 关从易到难：棋子 5 种渐增至 7 种、步数渐少、16 关起出现冰块（冰封棋子不可移动，卷入消除时改为破冰）；目标轮换为达到分数/收集指定颜色熊/清除全部冰块；通关解锁下一关，进度自动保存

均为纯前端 Canvas/DOM 实现（五子棋联机对战复用留言信箱的 Supabase 项目），无其他后端依赖。

## 小朋友（儿童向专区）

「小朋友」页是给孩子们准备的专区，首页是五个分类方框（一行两个，配手绘插图）：知识探索、创意手工、互动游戏、成长陪伴、展示舞台。分类下挂栏目（栏目与示例文章都写在 `js/kids-content.js`，加内容只改这个数据文件）：知识探索含小小科学家/动物世界/历史小火车/环球旅行家，创意手工含 DIY工坊/厨房小帮手/变废为宝/画画小课堂，互动游戏在四个小活动之外还有益智闯关/故事接龙/虚拟实验室/音乐工坊，成长陪伴含情绪小怪兽/安全小卫士/习惯养成打卡/睡前故事馆，展示舞台含问答小博士（答案点击展开）；游戏按钮大而圆、支持触屏：

- **涂鸦画板**：30 色蜡笔调色板（3 行 × 10 列）+ 3 档笔刷粗细，自由涂画，支持鼠标和触屏；画错了有橡皮和一键清空，画好了可保存为 PNG 图片
- **打地鼠**：30 秒倒计时，3×3 格子里随机冒出小熊头，点到 +1 分；小心偶尔出现的炸弹，点到 -2 分；最高纪录自动保存
- **口算小问答**：分「二年级下册」（100 以内加减、表内乘除）和「三年级下册」（两位数乘法、除数是一位数、一位小数加减）两个难度，各自一组 10 题，三个答案选项点选，答对打勾进下一题、答错抖动重试；做完显示用时和正确率，可再来一组

均为纯前端 Canvas/DOM 实现，无后端依赖。

## 你和我（私密角落）

「你和我」页需要账号密码才能进入，不同账号看到不同内容。账号和内容都在 `js/space-data.js`：

```js
{
  username: "ta",            // 改成你设置的用户名
  password: "20240101",      // 改成你设置的密码
  label: "给你的小天地 🌷",   // 登录后页面顶部的标题
  entries: [
    { date: "2026-07-20", title: "第一封信",
      text: ["段落一", "段落二"],
      photos: [] }            // 图片路径，如 ["images/us/1.jpg"]
  ]
}
```

想加内容就往对应用户的 `entries` 里加一条；想加账号就往 `SPACE_USERS` 数组里加一个用户。每条内容下方有留言区（带留言时间），两个账号都可以在对方的空间里留言对话；留言存在 Supabase 的 `space_comments` 表，首次使用需按 `SETUP-INBOX.md` 末尾的附录 SQL 建表（1 分钟）。用户可加 `nickname` 字段作为留言显示名，不写则显示用户名。注意：这是纯前端校验，懂技术的人查看源码能看到文件内容，请勿存放真正敏感的信息。登录状态只保存在当前标签页，关掉就要重新登录。

## 中英文切换

导航栏右侧有「中 / EN」切换按钮，界面文案即时切换，选择会保存在浏览器里（`localStorage`）。**首次访问默认英文模式**，手动切换后记住你的选择。文案字典在 `js/main.js` 顶部的 `I18N` 对象里，想改双语措辞直接改它。自己写的内容（生活碎碎念、「你和我」条目）通过可选的 `text_en` / `title_en` / `label_en` 字段提供英文版，不写则两种语言都显示中文原文。

## 想改样式？

整站采用「极简编辑风」（浅色杂志感）：米白纸底 + 墨黑文字 + 赭橙点缀，细分隔线代替卡片与阴影，标题用衬线字体（Noto Serif SC，Google Fonts，index.html 里引入），正文为系统无衬线。配色与字体集中在 `css/style.css` 顶部的 `:root` 变量里。
